# ublock-distractions

Opinionated filter lists to block algorithmic feeds, distractions and other
unwanted elements using uBlock Origin.

## Motivation

Many web platforms have increasingly been optimized to maximize user engagement,
often trough questionalble or even outright harmful practices.

The goal of this project is to remove the manifestations of such practices.

## Filter lists

| List      | URL                                    |
|-----------|----------------------------------------|
| All       | https://block.lejupla.de/all.txt       |
| Instagram | https://block.lejupla.de/instagram.txt |
| Reddit    | https://block.lejupla.de/reddit.txt    |
| YouTube   | https://block.lejupla.de/youtube.txt   |

## Usage

- Open *preferences/dashboard* of the uBlock Origin extension
- In the *import* field at the bottom of the *Filter lists* page, paste the
  URLs of the lists that you want to add.
- Click on the *Apply changes* button at the top left of the page

## Contributing

Contributions are welcome. Please use
[Discussions](https://github.com/tgrants/ublock-distractions/discussions)
to talk about proposals before creating issues or pull requests.

Web platforms get updated frequently, so a maintainer is required for the lists
that I don't use myself. If you're interested in becoming one, you are more than
welcome to. Filter lists with unpatched issues will be deprecated after a while.
